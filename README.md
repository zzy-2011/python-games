# Python 小游戏合集（pygame）

用 Python + pygame 写的休闲小游戏，和网页版（JS）分开存放，需要本地运行。

## 运行方法
```bash
pip install pygame
python <游戏目录>/main.py
```
例如：`python snake/main.py`

## 已收录
- guess 猜数字
- rps 石头剪刀布
- quiz 知识问答
- typing 打字练习
- snake 贪吃蛇
- sudoku 数独
- breakout 打砖块
- pong 弹球
